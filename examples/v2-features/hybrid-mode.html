Hybrid / Precompiled Mode

Combine build-time CSS generation with runtime compilation. Pre-generated critical CSS loads instantly; runtime handles only dynamic classes.

How Hybrid Mode Works

1

Build Time

Plugin extracts classes from source files and generates critical CSS

2

Page Load

Pre-generated CSS in <style> tag renders immediately — no FOUC

3

Runtime

Windrunner skips known rules, only compiles truly dynamic classes

Setup Guide

1. Generate critical CSS at build time

// vite.config.js
import { windrunnerPlugin } from 'windrunner/vite';

export default {
  plugins: [
    windrunnerPlugin({
      include: ['./src/**/*.{html,jsx,vue}'],
      output: 'windrunner-critical.css',
      injectIntoHtml: true,  // auto-inject into index.html
    })
  ]
};

2. Initialize runtime in precompiled mode

// main.js
import { windrunner } from 'windrunner';

windrunner({
  autoStart: true,
  precompiled: true,  // or mode: 'hybrid'
  // Runtime scans existing stylesheets for pre-generated rules
  // Only compiles classes NOT found in existing CSS
});
