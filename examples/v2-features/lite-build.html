Lite Build

A smaller bundle with core utilities only. ~35KB vs ~45KB for the full build. Excluded utilities trigger the onError callback with reason 'lite-mode-excluded'.

What's Included

Included (core utilities)

✓ Layout (display, position, overflow, z-index)
✓ Spacing (margin, padding)
✓ Sizing (width, height, min-w, max-w, min-h, max-h)
✓ Flexbox (flex, items-center, justify-between, gap)
✓ Grid (grid-cols, col-span, grid-rows)
✓ Typography (text-*, font-*, leading-*, tracking-*)
✓ Colors (bg-*, text-*, border-*)
✓ Borders (border, rounded, divide)
✓ Basic effects (shadow, opacity, ring)
✓ Basic variants (hover, focus, active, md:, lg:)

Excluded (extended)

✗ Transforms (scale-*, rotate-*, translate-*)
✗ Filters (blur-*, brightness-*, contrast-*)
✗ Transitions (transition-*, duration-*, ease-*)
✗ Animations (animate-*)
✗ Advanced group-* variants
✗ Advanced peer-* variants
✗ has-*, data-*, aria-* variants
✗ Arbitrary variants [&...]:

Usage

// Import from the lite build instead of the full build
import windrunner from 'windrunner/lite';
// or: import windrunner from '../dist/lite.esm.js';

windrunner({
  autoStart: true,
  onError: (className, context) => {
    if (context.reason === 'lite-mode-excluded') {
      console.warn(`Class "${className}" not available in lite build`);
    }
  }
});
