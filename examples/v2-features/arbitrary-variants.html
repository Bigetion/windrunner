Arbitrary Selector & At-Rule Variants

Escape the utility-class model when needed. Write any CSS selector or at-rule directly in your markup using bracket syntax.

[&>span] — Direct Child Selectors

Style specific child elements without additional classes

Live Demo

React Vue Svelte Solid

All <span> children share inline-block, padding, and rounded from the parent's arbitrary variant.

Markup

<div class="
  [&>span]:inline-block
  [&>span]:px-2
  [&>span]:py-1
  [&>span]:rounded
  [&>span]:text-xs
  [&>span]:font-medium
">
  <span>React</span>
  <span>Vue</span>
  <span>Svelte</span>
</div>

[@supports(...)] — Progressive Enhancement

Apply styles only when the browser supports a CSS feature

Backdrop Blur

This card uses backdrop-blur if supported. Falls back to solid background otherwise.

[@supports(backdrop-filter:blur(1px))]:backdrop-blur-md

CSS Grid Detection

[@supports(display:grid)]:grid

Complex Combinations

Combine arbitrary variants with built-in variants and each other

Syntax Examples

[&>span]:text-red-500 Direct child spans become red
[&:first-child]:rounded-t-lg Only first child gets top rounded
[@media(hover:hover)]:hover:underline Underline on hover, only on hover-capable devices
[@container(min-width:400px)]:grid-cols-2 2-column grid when container is wide enough
[@supports(display:grid)]:grid Grid layout only if browser supports it
[&_p]:text-slate-600 All descendant paragraphs
[&+div]:mt-4 Adjacent sibling div gets margin-top
